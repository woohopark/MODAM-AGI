# 이전 문서 분리·게시 기록 (이력)

작성일: 2026-10-08. 이 문서는 문서 분리 당시의 기록이다. 현재 구현 상태는 [STATUS](../STATUS.md)와 [첫 묶음 기록](FOUNDATION_REVIEW.md)을 따른다. 사용자 문서 검토 및 세 저장소 커밋 요청에 따라 프로젝트별 문서를 배치했다. 코드·테스트·의존성·마이그레이션·DB·서비스는 변경하지 않았다. 문서의 목표 계약과 실제 구현을 구분한다.

## 승인한 책임

- MODAM-AGI: Groq 단독 모델·오케스트레이션·권한/승인 흐름·초기 Evaluation/Observability.
- MODAM-RAG: 독립 MCP·문서 처리·근거 검색·Wiki·검색 지표.
- MODAM-ONTOLOGY: 독립 MCP·정의·매핑·KG·관계 탐색·초기 방법론·반자동 구축.
- Groq 외 기존 코드 삭제는 개발 계획에 명시했으며 이번 문서 반영에서는 실행하지 않았다.
- 인증 구현·실제 재고 변경/발주 초안/ERP 도구 소속·일부 기술은 구현 전 결정한다.

## 검증과 보존

문서 링크·프로젝트 소유권·미구현 표시·비밀 패턴·문서만 변경되는지 검사한다. 분리 이전 문서 12개는 docs/legacy에 원문 그대로 보존했다. 기존 44+8 테스트는 이전 단일 서비스 검증이며 새 MCP/Groq/SAP 검증이 아니다. 코드 변경이 없어 새 기능 테스트를 실행하지 않는다.

## 후속 구현

승인된 IMPLEMENTATION_PLAN에 따라 Groq 최소 구성 정리, 신규 오케스트레이션/평가/관측, 실제 두 MCP, 별도 변경 도구 연결을 단계별 구현·검증한다. 문서 커밋만으로 구현 완료를 보고하지 않는다. 코드 삭제·실제 서비스 작업의 실행 시점은 사용자 지시 범위에 맞춰 진행한다.
