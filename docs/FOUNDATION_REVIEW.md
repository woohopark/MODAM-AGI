## 변경 결과

기존 단일 서비스의 DB/API/업무/검색/그래프/고정 offline 모델과 실행 스크립트를 정리했다. Groq-only async 어댑터와 독립 상태 머신으로 바꾸고 모델·현재 신원/권한/전송 정책·읽기 도구를 작은 Protocol로 주입한다. 운영용 대역 모델을 제공하지 않는다.

이전 사용자/Role/승인 로직과 테스트의 검증 의도는 다음 인증/상태 묶음의 요구사항이다. 현재 첫 묶음은 같은 코드나 영속 서비스를 유지한다고 주장하지 않는다. 데이터/볼륨 초기화·기존 서비스 중지는 실행하지 않았다.

## 검토 시 주의할 실제 경계

Authority는 검증된 신원을 조회하는 서버 어댑터 계약이다. EvaluationAuthority는 합성 테스트 전용이며 서버 인증으로 연결하지 않는다. Request.subject_ref/cloud_allowed는 공개 API의 사용자 주장을 검증 없이 받아들이는 계약이 아니다.

상태 머신은 현재 실행의 메모리만 갖는다. request_id 멱등성·대화/승인 영속화·작업 복구가 없다. MCP 프로토콜/업무 계약 버전은 별개며 실제 협상을 검증하기 전 프로토콜 버전을 고정 구현하지 않는다. 신선도 검증은 담당 서비스의 정상화된 freshness를 사용하고 근거 버전 충돌을 추가로 검사한다. 사실 일치와 출처 정확도는 별도 실제 모델 평가가 필요하다.
