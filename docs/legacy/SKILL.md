# 목표 해결 절차

기준: [PRD.md](PRD.md), [AGENT.md](AGENT.md).

## 목표 확인

- 목표·제약·성공 조건·허용 도구를 확인한다.
- 필요한 입력이 없거나 해석에 따라 실행 결과가 달라지면 질문한다.

## 계획과 수행

- 각 단계의 목적, 사용할 도구, 필요한 입력, 기대 결과를 정한다.
- 허용된 행동을 수행하고 실제 결과를 기록한다.
- 데이터 변경·삭제·외부 전송은 내용을 확인받은 후 수행한다.

## 검증과 재계획

- 실제 결과를 단계의 기대 결과와 최종 성공 조건에 대조한다.
- 실패하면 도구 결과와 현재 상태를 확인하고 원인에 맞게 계획을 수정한다.
- 재실행 전에 이미 적용된 결과를 확인한다. 같은 실패를 이유 없이 반복하지 않는다.
- 정보·권한·도구·허용 한도 때문에 진행할 수 없으면 이유와 필요한 지원을 알린다.

## 결과 보고

- 달성한 결과와 확인 근거를 제시한다.
- 미완료 내용과 한계를 명시한다. 계획만 세운 상태를 수행 완료로 보고하지 않는다.
