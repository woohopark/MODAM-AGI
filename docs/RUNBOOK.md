# 실행 안내 — 문서 전환 중

현재는 새 아키텍처의 문서 승인·배치 단계다. Groq 최소 구성 및 세 서비스의 신규 실행 명령은 코드 전환 후 실제 검증해 작성한다. 이번 문서 변경은 서비스·DB·키 설정을 변경하지 않는다.

이전 구현 실행 안내는 [이력](legacy/docs/RUNBOOK.md)에 보존한다. Groq 외 코드 제거 이후에는 이전 DB/CLI/API 명령을 새 실행 안내로 사용하지 않는다. 신규 구현/검증 상태는 [AGI](../STATUS.md), [RAG](https://github.com/woohopark/MODAM-RAG/blob/main/STATUS.md), [ONTOLOGY](https://github.com/woohopark/MODAM-ONTOLOGY/blob/main/STATUS.md)를 확인한다.
